API keys

Read-only bearer tokens so external tools can pull logs via the API. A key can read events, the live tail, stats and the device list — it can never manage users, keys, or anything else.

Use a key with an Authorization: Bearer header, e.g.
curl -H "Authorization: Bearer <key>" <this-site>/api/events.csv?window=86400

Organize systems

Group your firewalls into categories and drag them into the order you want on the Overview. Double-click a category name to rename it. This is display-only — it never touches your devices.json, so keep that in any order (e.g. by UDP port). Everyone sees the same arrangement.
